📊 Mini CRM – Client Lead Management (Task 2)

This project is a **Mini CRM (Client Lead Management System)** built using **Node.js, Express, and MongoDB**.  
It allows users to **add and view client leads** through REST APIs.

This project is developed as part of **Task 2** for learning full stack web development.

---

🚀 Features

- Add new client leads
- View all leads
- REST API based backend
- MongoDB database integration
- Clean and simple project structure

---

🛠️ Tech Stack

- Backend: Node.js, Express.js
- Database: MongoDB
- ODM: Mongoose
- Tools:MongoDB Compass, Postman / Thunder Client
- Environment Variables: dotenv
